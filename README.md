## Coffr
This project is a small demonstration of the actual working of a bank.It mimics the the system that performs
various kinds of transactions of currency as per our requirement.
This project is made by using concepts of Java i.e. Springboot framework,hibernate,API creation.

## Technologies used:
Springboot
SQL
React

The Springboot with the help of hiberanate builds the structure of the project.Using the Springboot framework we create methods
to access,update the data in the database.React helps us display a user-friendly User Interface which allows them to utilise
the services.The SQL stores data about users.It has various tables created representing the components.
Every user has a unique customer id and account numbers which are auto generated by SQL.

## Flow of work:
1. The user signs in to the application through the SignUp page if the user does not have an existing account or through the Login page if the user has an account.
2. The user is directed to the Home Page where the user sees the users profile on the right corner. In the center the user sees four boxes: three boxes represent the types of accounts and the fourth box offers a drop down menu of services.
3. The user can select the type of account that the user wants to choose and create an account for that type.
4. If a new account does not already exist the user creates an account. If an account of that type already exists for the user the user is directed to the account details such, as account number, name, balance and available services like withdraw, deposit or viewing the transactions.
5. The user is provided with a text box to enter the sum that the user wants to withdraw or deposit. The transaction is carried forward using that sum. The necessary changes are made.
6. The user can terminate the account if required by clicking on the 'terminate' button provided.

## Key Features
Session-based authentication for login and signup built properly
CORS configuration works smoothly ensuring reliable communication between the React frontend and Spring Boot backend
Scheduled interest updaters are automatic providing recurring balance updates with no manual intervention
Multithreading safety ensures that transactions stay accurate even when multiple actions hit the same account at the same time
Some images of the session-based authentication, for secure login and signup built properly have been added to the repository.
